# audio-hotkeys v1.6.0 릴리스 노트

후원 QR 공개 컨펌(2026-08-30)이 나오면서 7/25부터 묶여 있던 v1.5.0·v1.6.0을 함께 게시합니다.

## v1.6.0 (2026-08-01)
- 기본 글꼴을 **라인시드(LINE Seed KR)**로 변경하고 앱에 번들해 별도 설치 없이 동작합니다.
- 설정 창을 **스냅샷 / 화면 설정 / 정보** 3개 탭으로 재정렬해 한 화면의 혼잡을 줄였습니다.

## v1.5.0 (2026-08-01)
- **설정 창을 여는 단축키 추가** (Ctrl+Alt+Shift+`.`). NumPad `.`와 메인 키보드 `.` 둘 다 동작하며, 이미 열려 있으면 창을 앞으로 가져옵니다.

## v1.4.5 (2026-08-01)
- 저장 단축키(Ctrl+Alt+Shift+NumPad)가 실제 키보드에서 동작하지 않던 문제 수정. Windows가 Shift+NumPad에서 Shift를 임시 해제하는 동작 때문에 단축키가 발화되지 않았습니다.

## 게시 방법 (클로드 코드가 못 올린 이유)

릴리스 생성은 대외 공개 액션이라 자동 모드 분류기에 차단됐습니다. 아래 한 줄을 직접 돌리시면 됩니다.
첨부할 exe는 이미 v1.6.0으로 빌드돼 있습니다 (`dist\audio-hotkeys.exe`, 2026-08-30 06:14, 23,008,130바이트).

```bash
gh release create v1.6.0 dist/audio-hotkeys.exe --repo kuroicode-beep/audio-hotkeys --title "audio-hotkeys v1.6.0" --notes-file docs/릴리스노트_20260830_v1.6.0.md
```

게시하면 사이트의 「Windows용 다운로드」 버튼(`releases/latest/download/audio-hotkeys.exe`)이 자동으로 v1.6.0을 가리킵니다. 지금은 v1.4.4를 주고 있습니다.
